## Goal
A logged-in person sees Home with one beautiful card per course (from `manifest.json`, sorted by `order`). Tapping a card opens the course with exactly four tiles:
Overview, Content, Test, Report. A tile whose data is empty or broken shows the owner's Gujarati message instead of opening. Nothing here reads personal data.

## Design (made here, do not re-discuss)
- Data flow: Home calls `loadManifest()`, then `loadCourse(id)` per course and uses only `card`. A course whose `card` is `empty`/`invalid` stays on Home as a disabled card with its manifest title and the "not available" message (never hidden, never a crash).
  Manifest `unavailable`/`invalid` (offline first run, bad file) = one calm message card with a Retry button. No courses = a friendly empty card. While loading: 2 skeleton cards (tokens only, no spinner library).
- Routes (hash router, inside the Shell): `/` Home, `/course/:courseId` the 4 tiles, `/course/:courseId/overview|content|test|report` = placeholder screens that say "Coming in a later update" until P06 (reader: overview + content), P07 (test game) and P08 (report) replace them. An unknown or invalid `courseId` shows the not-available state with a Back button.
- Tile state: Overview, Content and Test come from `loadCourse(courseId)` (`ready` = opens; `empty` or `invalid` = disabled look, `aria-disabled`, and the message below it). Report is always open (P08 builds it from what the person did, not from developer data).
- "Not available" text (owner's exact Gujarati, SPEC C3): `હાલ આ માહિતી ઉપલબ્ધ નથી, રાહ જુઓ. ટૂંક સમયમાં માહિતી ઉપલબ્ધ થશે` in `en.json` key `course.unavailable` (the one deliberately Gujarati string; read `i18n.test.ts` first, it may assume ASCII). One shared component `NotAvailable` in `src/modules/home/` (P06/P07 reuse it by importing from `core/ui` later if they need it: move it then).
- Cover image: optional; `<img loading="lazy">` from `contentUrl('courses/<id>/<cover>')`, `alt` = course title; no cover = an icon on a soft Surface. Titles and descriptions are plain text (never HTML).
- Look: `Card`, `Tile`, tokens only, soft corners, light/dark both, auto-fit grid (1 column on 360 px, 2-3 on wide screens), smooth press/hover and a short fade-in; no new dependency. All text in `en.json` (except the Gujarati line above is also there). Icons from lucide-react, `aria-hidden`.
- Boundaries: `src/modules/home` may import `core/content`, `core/ui`, `core/i18n`, `core/wire`; never other modules, never `core/storage`.
